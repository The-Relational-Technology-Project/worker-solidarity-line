# Worker Solidarity Line

An anonymous peer-support chat tool for workers dealing with workplace issues — wage theft, retaliation, discrimination, union-busting, and gig misclassification.

## What is this?

Worker Solidarity Line connects workers facing workplace problems with trained peer counselors through anonymous chat. Workers can start a conversation without creating an account, and volunteers can sign up to provide support. Includes an admin panel for managing conversations and supporters.

## Features

- **Anonymous chat** — Workers start a peer support conversation with no signup required
- **Peer counselors** — Trained volunteer supporters matched to incoming conversations
- **Issue categories** — Focused on wage theft, retaliation, discrimination, union-busting, and gig worker misclassification
- **Volunteer signup** — Onboarding flow for people who want to support workers
- **Admin panel** — Tools for managing conversations, supporters, and the support queue

## Tech stack

- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- [Supabase](https://supabase.com/) for auth, database, and real-time chat
